# 망원경 설치 실험실

중학생이 소형 적도의식 굴절망원경의 설치와 관측 순서를 직접 조작하며 익히는 7단계 웹 시뮬레이션입니다.

## 주요 학습 단계

아래는 현재 실행되는 과정입니다. 기존 순서를 유지하며 1·2단계만 새 삼각대·가대 실습으로 교체했습니다. 새 교육과정 설계와 구현 현황은
[개발 방향](docs/DEVELOPMENT_DIRECTION.md) 및 [교육과정 v2](docs/CURRICULUM_V2.md)에 기록합니다.
후속 작업 전 두 문서를 먼저 읽어 주세요. v2 단계 정의는 아직 실행 흐름으로 전환되지 않았습니다.

1. 삼각대 설치와 수평 조절
2. 적도의 가대 장착과 고정
3. 무게추 설치와 안전 잠금
4. 경통 장착
5. 적경·적위축 균형 조절
6. 파인더 정렬
7. 접안렌즈 설치와 목성 초점 조절

## 로컬 실행

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 교육과정 정의 검증

`pnpm test:curriculum`으로 새 7단계의 선행 관계와 현재 기능/계획의 구분을 검사합니다.
`pnpm test:tripod`는 다리별 기하 계산, 안전 차단, 최종 확인, 저장 복원을 검사합니다.
`pnpm test:mount`는 가대의 안착·고정·방향 설정·저장 및 다리 이미지 연결점 연속성을 검사합니다.
삼각대 계산 가정과 시각 표현의 한계는 [삼각대 교육 모형](docs/TRIPOD_MODEL.md)에 기록합니다.
`pnpm build`는 타입 검사와 실제 운영 페이지의 결합 좌표 CSS 포함 검사를 수행합니다.

## 배포

이 저장소는 Next.js 프로젝트이며 GitHub 저장소를 Vercel에 연결해 배포할 수 있습니다. `main` 브랜치에 반영된 변경은 Vercel 운영 배포로 연결하고, 다른 브랜치는 미리보기 배포로 검수하는 방식을 권장합니다.

학생의 진행 상태는 각 브라우저의 로컬 저장소에 자동 저장됩니다.
