# 망원경 설치 실험실 — 합의한 개발 방향

기록일: 2026-09-04. 이 문서는 사용자와 합의한 후속 개발 기준이다.
목표는 정답 위치를 외우는 조립 게임이 아니라, 실제 장비 앞에서 관찰하고 판단할 수 있는 교육 시뮬레이션이다.

## 변하지 않아야 할 원칙

1. 관찰 → 판단 → 조작 → 재확인의 반복을 모든 단계에 적용한다.
2. 이미지, 결합점, 회전축, 조작 판정은 같은 장비 상태와 좌표를 사용한다.
3. 수평·균형·정렬·초점을 구분한다. 숫자를 숨기는 것만으로 물리 모형을 대체하지 않는다.
4. 다리 높이 → 상판 기울기 → 기포 위치, 부품 무게·거리 → 회전 경향처럼 인과관계를 구현한다.
5. 안전한 시행착오는 허용하고 결과를 보여준다. 잠긴 장치는 왜 움직이지 않는지 설명한다. 위험한 행동은 실행 전에 차단한다.
6. 힌트는 관찰 위치 → 원리 → 구체적 행동 순서로 제공한다. 안전 경고는 요청 없이 즉시 보여준다.
7. 최종 균형은 관측 부속품을 포함한 상태에서 점검한다. 구성 변경 후에는 기존 균형 판정을 재검토한다.
8. 결과는 점수보다 설치 리포트: 독립 수행, 힌트 사용, 실수 수정, 재연습 항목. 기록하지 않은 성취를 추정하지 않는다.
9. 실물과 닮은 캐릭터형 이미지를 유지한다. 이동하는 부품을 분리하고 동일 결합점에 연결한다. 전면 3D 전환을 필수로 삼지 않는다.
10. 마우스 정확도·속도를 과학적 이해와 혼동하지 않는다. 키보드 조작에도 같은 장비 상태 판정을 적용한다.

## 개발 순서와 현재 상태

| 순서 | 작업 | 상태 |
| --- | --- | --- |
| 1 | 기준 장비·새 7단계·단계별 완료 증거 정리 | 일반형 장비로 진행하는 데 사용자 동의. 설계 기준 및 코드 정의 작성 |
| 2 | 장비 상태·안전 규칙·행동 기록의 공통 구조 | 삼각대·가대 reducer와 안전 판정·이벤트 기록 구현. 나머지 단계는 기존 구조 |
| 3 | 수평·균형과 부품 움직임 연결 | 다리 연장부 이미지·상판·기포 연결 및 가대 공통 결합점 구현. 축 균형은 미구현 |
| 4 | 파인더 정렬·극축 정렬·목표 탐색 | 기존 파인더 연습을 확장할 예정 |
| 5 | 설치 리포트 | 미구현 |

첫 물리 조작 구현은 1단계부터 진행한다. 위 표의 2번 공통 구조를 최소 범위로 만든 뒤 다리 높이와 기포를 연결하고, 이를 다른 단계의 표준으로 삼는다.

## 현재 버전의 한계 — 완료로 오해하지 말 것

- 현재 실행 순서는 기존 7단계를 유지하며, 1·2단계만 새 삼각대·가대 실습으로 교체했다. 전체 v2 전환 완료가 아니다.
- 기존 단계: 삼각대 → 가대 → 무게추 → 경통 → 축 균형 → 파인더 → 접안부·초점.
- 삼각대 수평은 다리별 연장량과 지면 높이를 계산한다. 축 균형·파인더·초점은 아직 기존 고정 중앙값 판정이며 교체 대상이다.
- 삼각대는 고정 발 위치·작은 기울기 교육 모형이다. 다리 연장부와 상판 높이는 2D 이미지 분할·변형으로 표현하며 완전한 강체 3D 모형은 아니다. 일부 다리만 펼친 중간 그림은 아직 없다.
- 가대의 기본 방위·위도 설정은 개념도로 표시한다. 실제 가대 사진이 3차원 회전하는 기능과 정밀 극축 정렬은 아직 없다. 3단계 이후의 기존 조립 그림에는 새로운 다리 변형이 아직 적용되지 않는다.
- 극축 정렬과 목표 천체 탐색, 과정 기반 리포트는 아직 없다.
- 잠금 버튼을 눌렀다는 사실과 실제 안전한 고정을 확인했다는 사실은 구분해야 한다.
- 배포 때 CSS가 누락된 전력이 있다. `app/assembly-layout.css`와 `scripts/verify-assembly-build.mjs`를 유지하고 운영 빌드에서 확인한다.

- 새 단계로 전환할 때 기존 진행 저장값을 숫자 인덱스로 재해석하지 않는다. 버전이 다른 저장 형식을 분리하고 기존 값을 보존한다.
- 단계 재구성 시 현재/미완료/구현 완료를 문서에 명시하고 테스트 결과를 갱신한다.

## 후속 작업 기록 — 삼각대 상태·수평 구현 (2026-09-04)

- 준비물대 드래그/키보드 설치 → 세 다리 펼침 → 발끝 지지 확인 → 상부 관찰 → 받침·한 다리 잠금 해제·길이 조절·재잠금 → 최종 확인 흐름을 구현했다.
- 서로 다른 두 지면과 다리별 길이로 기울기를 계산한다. 모든 다리를 같은 값이나 중앙값에 놓는 것으로 통과하지 않는다. 여러 전체 높이에서 수평 해가 가능하다.
- 잠긴 다리 조절, 받침 없는 잠금 해제, 동시에 두 다리 해제, 풀린 다리에서 손 떼기, 불안정한 상태의 가대 단계 진입을 차단하고 원인을 안내한다.
- 관찰·선택·조절·힌트·차단 이벤트를 최근 160건까지 기록한다. 아직 전 과정 리포트나 교사용 서버 수집은 아니다.
- 저장 키는 `telescope-lab-progress-tripod-v2`. 이전 `telescope-lab-progress`는 삭제하지 않고 새 실습은 별도로 시작한다. 이후 전체 교육과정 v2 이행 시 다시 명시적으로 버전을 구분할 것.
- 브라우저에서 원 밖/안 드롭, 상부 시점, 잠금 차단, 키보드 길이 조절, 기포 이동, 수평이어도 잠금 전 진행 차단, 중간 상태 복원, 완료 후 2단계 진입과 진도 복원을 확인했다.
- PC 약 1280×720 및 모바일 390×844에서 시각 확인했다. PC는 관찰 화면과 설명을 유지하며 조작부만 스크롤, 모바일은 조작부에도 기포 표시. 가로 넘침 없음.
- 자동 검증: 삼각대 16개 + 교육과정 4개 통과. 운영 빌드 및 기존 결합 좌표 CSS 검사 통과.
- 운영 빌드를 별도 로컬 포트에서 실행해 관측지 B의 키보드 설치·수평 조절·최종 확인을 끝까지 진행했다. 펼친 모습과 상부 모습을 시각 확인했고, 콘솔 오류·경고는 없었다.

## 후속 작업 기록 — 다리 이미지 연동·2단계 가대 (2026-09-04)

- 삼각대 원본 이미지를 상부·다리·연장부·발끝으로 나눠 렌더링한다. 다리별 연장량을 반영하며 발끝 기준점은 지면 높이에 고정한다. 선택한 다리의 확대 보기도 추가했다.
- 상판 중심 높이는 세 유효 지지 높이 평균에 연결한다. 한쪽 연장 시 상판이 반대로 내려가 보이던 초기 시각 오류를 점검 중 수정했다. 관측지 2개 × 각 다리 3개 길이 조합에서 연결 경계 연속성을 테스트한다.
- 가대 안착과 고정 상태를 분리하고 기준 홈 확인·실제 밑면 기준 드롭·하부 확대 조임·유격 확인·기본 방위/고도 설정·조절 나사 정리·최종 확인을 구현했다.
- 하부 고정 전에 손을 떼거나 측면 나사로 하부 고정을 대신하는 행동을 차단한다. 무게추/경통이 올라간 뒤 가대 설정도 이 연습 범위에서는 잠근다.
- 새 저장 키는 `telescope-lab-progress-mount-v3`. 이전 두 키를 보존하며 직전 버전의 유효한 삼각대만 이어받고 가대 완료는 새로 확인한다. 새 가대 중간 상태와 3단계 진도 복원을 브라우저에서 확인했다.
- PC 1280×800, 모바일 390×844에서 삼각대 전체/확대, 가대 안착/하부 확대/방향 개념도를 확인했다. 위치·방향 오답 드롭과 안전 차단, 최종 확인 후 무게추 단계 연결을 직접 시행했다.
- 테스트: 기존 20개 + 새 가대·연장부 15개 = 35개 통과. 운영 빌드 및 결합 CSS 검사 통과. 운영 서버에서 3단계 진도 복원, 2단계 재방문과 조립 이미지, 가대 장착 후 다리 조절 차단을 확인했으며 해당 운영 점검 중 콘솔 오류·경고는 없었다.
- 다음 구현 후보는 3단계 무게추의 봉 끝 안전장치·고정·받침 상태와 공유 그림 연결이다. 3단계부터 뒤쪽 흐름은 아직 기존 버전임을 유지한다.
- 로컬 작업만 진행했으며 push/운영 배포는 하지 않았다.
