# 망원경 설치 실험실 — 합의한 개발 방향

기록일: 2026-09-04. 이 문서는 사용자와 합의한 후속 개발 기준이다.
목표는 정답 위치를 외우는 조립 게임이 아니라, 실제 장비 앞에서 관찰하고 판단할 수 있는 교육 시뮬레이션이다.

## 변하지 않아야 할 원칙

1. 관찰 → 판단 → 조작 → 재확인의 반복을 모든 단계에 적용한다.
2. 이미지, 결합점, 회전축, 조작 판정은 같은 장비 상태와 좌표를 사용한다.
3. 수평·균형·정렬·초점을 구분한다. 숫자를 숨기는 것만으로 물리 모형을 대체하지 않는다.
4. 다리 높이 → 상판 기울기 → 기포 위치, 부품 무게·거리 → 회전 경향처럼 인과관계를 구현한다.
5. 안전한 시행착오는 허용하고 결과를 보여준다. 잠긴 장치는 왜 움직이지 않는지 설명한다. 위험한 행동은 실행 전에 차단한다.
6. 힌트는 관찰 위치 → 원리 → 구체적 행동 순서로 제공한다. 안전 경고는 요청 없이 즉시 보여준다.
7. 최종 균형은 관측 부속품을 포함한 상태에서 점검한다. 구성 변경 후에는 기존 균형 판정을 재검토한다.
8. 결과는 점수보다 설치 리포트: 독립 수행, 힌트 사용, 실수 수정, 재연습 항목. 기록하지 않은 성취를 추정하지 않는다.
9. 실물과 닮은 캐릭터형 이미지를 유지한다. 이동하는 부품을 분리하고 동일 결합점에 연결한다. 전면 3D 전환을 필수로 삼지 않는다.
10. 마우스 정확도·속도를 과학적 이해와 혼동하지 않는다. 키보드 조작에도 같은 장비 상태 판정을 적용한다.

## 개발 순서와 현재 상태

| 순서 | 작업 | 상태 |
| --- | --- | --- |
| 1 | 기준 장비·새 7단계·단계별 완료 증거 정리 | 일반형 장비로 진행하는 데 사용자 동의. 설계 기준 및 코드 정의 작성 |
| 2 | 장비 상태·안전 규칙·행동 기록의 공통 구조 | 1~7단계 reducer와 판정·이벤트 기록 구현. 전체 리포트는 별도 작업 |
| 3 | 수평·균형과 부품 움직임 연결 | 다리·기포·공통 결합점, 부속품 포함 질량·거리 기반 두 축 균형과 2D 시험 보기 구현 |
| 4 | 파인더 정렬·극축 정렬·목표 탐색 | 기준별 정렬·목성 탐색 구현. 정밀 극축 정렬은 미구현 |
| 5 | 설치 리포트 | 미구현 |

첫 물리 조작 구현은 1단계부터 진행한다. 위 표의 2번 공통 구조를 최소 범위로 만든 뒤 다리 높이와 기포를 연결하고, 이를 다른 단계의 표준으로 삼는다.

## 현재 버전의 한계 — 완료로 오해하지 말 것

- 현재 7개 번호를 유지하되 5단계 안에 부속품 준비를 먼저 배치했다. 전체 v2 전환 완료가 아니다.
- 실행 단계: 삼각대 → 가대 → 무게추 → 경통 → 부속품·두 축 균형 → 파인더 정렬 → 초점. 6·7단계의 중복 장착을 제거했다.
- 삼각대 수평은 다리별 연장량과 지면 높이, 축 균형은 교육용 질량·거리 모형으로 계산한다. 파인더는 두 광축·공유 천체 좌표, 초점은 초점면 거리·번짐·관찰 증거로 판정한다.
- 삼각대는 고정 발 위치·작은 기울기 교육 모형이다. 다리 연장부와 상판 높이는 2D 이미지 분할·변형으로 표현하며 완전한 강체 3D 모형은 아니다. 일부 다리만 펼친 중간 그림은 아직 없다.
- 가대의 기본 방위·위도 설정은 개념도이며 실제 가대가 3차원 회전하지 않는다. 3~7단계에서 공유 장착 그림을 이어 쓰고, 5단계 축 시험은 별도 2D 단면 모형으로 표현한다. 연속 강체 운동이나 정밀 극축 정렬은 아니다.
- 기준별에서 목성으로의 목표 탐색은 구현했다. 정밀 극축 정렬과 전 과정 기반 리포트는 아직 없다.
- 잠금 버튼을 눌렀다는 사실과 실제 안전한 고정을 확인했다는 사실은 구분해야 한다.
- 배포 때 CSS가 누락된 전력이 있다. `app/assembly-layout.css`와 `scripts/verify-assembly-build.mjs`를 유지하고 운영 빌드에서 확인한다.

- 새 저장 키는 `telescope-lab-progress-mount-v3`. 이전 두 키를 보존하며 직전 버전의 유효한 삼각대만 이어받고 가대 완료는 새로 확인한다. 새 가대 중간 상태와 3단계 진도 복원을 브라우저에서 확인했다.

## 후속 작업 기록 — 3단계 무게추 설치

- 봉·축 잠금 관찰 → 봉 끝 안전장치 보관·무게추 나사 풀기 → 봉 끝으로 드래그 → 받친 채 임시 위치 조절 → 고정나사·안전장치 → 미끄러짐 확인 → 최종 확인을 구현했다.
- 삽입 구멍을 막는 나사, 안전장치가 남은 봉 끝, 잘못된 드롭, 받침 없는 조작, 잠긴 무게추 이동, 고정 대신 클러치를 푸는 행동에 원인별 피드백을 추가했다.
- 기존 무게추 이미지를 분리해 공유 삼각대·가대 그림에 연결했다. 무게추 중심과 실제 봉 끝을 기준으로 드롭을 판정하며, 확대 시에도 같은 좌표를 사용한다. 새 그림 생성 없이 기존 이미지 픽셀을 재사용했다.
- 임시 위치는 여러 값에서 완료 가능하다. 아직 경통·부속품의 질량을 계산한 축 균형이 아니다. 기존 4단계 이후 조립 그림 통합은 남아 있다.
