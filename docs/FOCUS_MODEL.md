# 7단계 초점·관측 — 구현 모형과 한계

## 구현 (2026-09-07)

6단계의 목성 중심 확인과 5단계의 관측 구성·균형 확인이 유효해야 시작한다. 저배율 접안 시야 열기 → 상 관찰 → 초점 손잡이 조절 → 손을 떼고 진동 기다리기 → 위성 빛점과 목성 경계 비교 → 보인 특징 기록 → 수동 관측 확인 순서이다.

- 초점값·목표 50·정답 방향 안내·자동 성공 타이머를 실행 화면에서 제거했다. 초점의 양쪽에서 번짐이 증가하고, 초점을 지나쳤으면 돌아올 수 있다. 일부러 지나치거나 방향을 바꾸는 것을 완료 조건으로 강요하지 않는다.
- 포커서 손잡이 드래그, 좌우 방향키, 안쪽/바깥쪽 버튼을 같은 reducer로 처리한다. 큰 조절과 작은 조절은 같은 손잡이를 돌리는 양이며 별도의 실제 감속장치 사양이 아니다.
- 손잡이에 손을 대거나 돌리면 기계적 진동을 표시한다. 손을 뗀 뒤 1.4초 후 관찰 가능한 상태가 된다. 진동 중에는 관찰·확인을 차단한다. 완료는 시간이 아니라 현재 초점·관찰 증거·특징 기록·수동 확인으로 판단한다.
- 안정된 대기/일렁이는 대기는 별도 광학 흐림과 위치 변화로 표현한다. 대기를 바꿔도 초점 위치는 변하지 않는다. 일렁임이 있다는 이유로 올바른 초점을 틀렸다고 하지 않는다.
- 관찰 시 현재 위치·대기·설명을 최대 12건 기록한다. 마지막 관찰 위치를 작은 시야와 같은 크기의 비교 보기로 재현한다. 저장된 이미지나 정확한 순간 캡처가 아니다.
- 목성의 가장자리와 위성의 빛점을 직접 확인하도록 한다. 특징 체크만으로 흐린 상을 통과할 수 없다. 초점 조절·손 접촉·대기 변경은 관찰 증거를 취소한다. 접안렌즈 고정나사와 초점 손잡이 혼동, 렌즈 접촉에는 원인별 피드백을 제공한다.
- 완료 화면은 해당 초점 실습의 방향 전환 횟수·힌트 횟수만 보여준다. 방향 전환을 실제 초점 통과나 독립 수행의 증거로 해석하지 않는다. 전체 설치 평가 리포트는 미구현이다.

## 물리·시각 가정

소형 굴절망원경의 가상 70/700 mm 광학계, 시야 지름 1°, 목성 지름 40초각을 이용한 교육 모형이다. 특정 실제 장비 사양이나 관측 날짜의 천체 배치가 아니다. 광선 원뿔에서 축방향 초점 오차 Δz에 따른 착란원 반경을 |Δz|/(2×F수)로 계산하고, 이를 가우시안 번짐으로 근사한다. 초점 오차와 별도의 대기 번짐을 합성한다. 파동광학 PSF, 색수차, 구면수차, 실제 눈의 응답은 재현하지 않는다.

이동 범위 12~36, 연습 A/B의 초점면 23.6/24.8, 큰 조절 0.8·작은 조절 0.1, 허용 오차 0.16은 mm 단위의 가상 모형 수치이다. 사용자 화면에는 정답 위치를 표시하지 않는다. 실제 포커서의 이동 범위·회전수·백래시와 같다고 주장하지 않는다. A/B는 관측자의 초점 조건이 다를 수 있음을 설명하는 두 연습 조건이다.

목성은 작은 원반과 옅은 두 띠, 위성은 빛점으로 표현한 과학적 도식이다. 실제 사진처럼 정밀한 표면 이미지가 아니며 영상의 확대와 초점 이동을 분리한다. 기본 5× 중앙 확대는 프로그램의 학습용 확대이고 접안렌즈 교환이나 실제 광학 배율 변화가 아니다. 전체 시야에서는 작게 보인다. 6단계에서 확인한 광축 오프셋을 이어받는다. 기록 비교에도 같은 시야 크기를 사용한다.

시간에 따른 일주운동은 이 실습에서 멈춘다고 표시한다. 실제 관측에서는 수동 추적, 정밀 극축 정렬, 눈 간격·광축 위치에 따른 비네팅, 대기·경통 열평형, 고배율 접안렌즈 교환 등이 추가로 필요하다. 해당 기능은 이번 완료에 포함하지 않는다. `prefers-reduced-motion` 사용 시 대기·진동 애니메이션을 줄이되 관찰 대기 및 판정은 동일하게 유지한다.

## 저장·복원

새 키 `telescope-lab-progress-focus-v8`를 사용하며 이전 키들을 삭제하지 않는다. 검증된 1~6단계만 이어받고 과거 초점 완료/숫자 50을 새 관측 성취로 인정하지 않는다. 현재 초점 위치·조건·관찰 기록을 복원한다. 새로고침 때 손 접촉과 진행 중 타이머는 이어받지 않으며, 진동/접촉 중이던 기록은 재관찰을 요구한다. 완료는 플래그만 보지 않고 초점 기하·현재 위치 관찰·특징 선택을 재검증한다.

관측을 연 뒤 6단계 재방문은 관찰 전용이다. 1~5단계의 장착 상태·균형 위치는 유지한다.

## 검증

- `scripts/focus.test.mjs` 18개 추가, 전체 107개 통과: 선행 조건, 양쪽 번짐, 서로 다른 초점면, 조절 후 무효화, 이전 타이머 차단, 손 접촉·진동, 수동 관찰 증거, 오답 특징, 초점 통과/되돌림, 대기 독립성, 이동 한계, 안전 피드백, 복원 및 이력 제한.
- PC 1280×800: 초기 번짐, 선명한 상, 초점 통과 후 번짐을 실제 화면에서 확인. 흐린 상태에서 특징 선택만으로 통과하지 않음, 방향키 복귀와 중간 저장 복원을 확인했다.
- 모바일 390×844: 실제 드래그 이동, 버튼 조절, 대기 조건 변경과 관측 확인을 시행했다. 작은 비교 시야가 본 시야를 가리지 않도록 모바일에서는 같은 크기 전환 비교를 사용한다. 가로 넘침 없음.
- 최종 운영 빌드·TypeScript·결합 CSS 검사와 새 초점 모듈 lint 통과. 운영용 로컬 서버에서 완료 기록 복원·동일 크기 비교를 확인했으며 해당 점검의 콘솔 오류·경고는 없었다. 6단계 재방문에서 조준 변경 차단도 확인했다. 전체 lint의 기존 오류를 정리하는 작업은 이번 범위가 아니다.
