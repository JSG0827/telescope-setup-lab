# 2단계 가대 설치 — 구현 기준과 한계

2026-09-04. 일반형 소형 수동 독일식 적도의 교육 모형이다. 특정 제조사의 실제 제품이나 조임 토크를 재현하지 않는다.

## 역할과 흐름

가대의 기준 홈과 삼각대 기준부를 맞추고 하부 손잡이로 결합을 고정하는 역할, 방위/고도 조절부가 극축의 방향을 설정하는 역할을 구분한다. 원리 참고: [Sky-Watcher EQ3-2/EQ5 설명서](https://inter-static.skywatcher.com/upfiles/en_download_caty01316546576.pdf), 인쇄 6·8쪽 결합, 12쪽 방위·고도 조절. 해당 그림의 특정 실물 모델을 단정하는 근거로 쓰지 않는다.

1. 유효한 삼각대 수평·잠금 완료 상태가 필요하다.
2. 기준 홈 방향 확인 후 드래그/Enter 안착. 드롭은 포인터가 아니라 움직이는 가대 밑면 표시와 실제 SVG 결합 원의 일치로 판정한다.
3. 안착 후 받침을 유지한다. 하부 확대에서 중앙 결합 손잡이를 ¼회전씩 조인다. 4번은 가상 실습 단계이며 실물의 요구 회전 수가 아니다. 밀착 이후 추가 조임은 차단한다.
4. 받친 채 유격 확인을 해야 하부 고정 성취로 인정한다. 유격을 검사했다는 화면 조작을 실제 힘/토크 측정으로 표현하지 않는다.
5. 방위와 고도를 각각 조절한다. 가상 관측지는 북위 37°이며 실제 학교 위치와 무관하다. 기본 설정 통과 범위는 북쪽 ±2°, 위도 ±2°로 교육용이다.
6. 양쪽 방위·고도 나사의 맞닿음을 확인한다. 다시 조절하려면 반대편 나사를 조금 풀어 여유를 만드는 행동을 먼저 한다. 실제 나사의 개수·고정 방식은 설명서마다 다르다.
7. 최종 확인 후 무게추 단계로 진행한다. 이를 정밀 극축 정렬 완료로 기록하거나 표시하지 않는다.

## 시각 표현

- 기존 캐릭터형 비트맵을 재사용한다. 삼각대와 가대는 같은 SVG 좌표와 계산된 상판 결합점을 쓴다. 가대 원본의 하부 돌출부는 클리핑해 교육용 어댑터 결합면으로 표현하며 실제 나사 규격 호환을 의미하지 않는다.
- 하부 화면은 시점 재구성된 새 3D 모델이 아니라 결합부 확대다. 회전 표식과 틈은 교육용 강조다. 실제 실습에서 장비 아래로 머리를 넣으라는 지시가 아니다.
- 방위·고도는 서로 다른 투영의 개념도에서 움직인다. 가대 비트맵 자체는 3차원 회전하지 않는다. 상판 수평·극축 기본 방향·정밀 극축 정렬은 서로 다른 완료 조건이다.
- 1·2단계는 공유 삼각대 그림을 사용한다. 3~7단계는 아직 기존 조립 그림과 로직이어서 다리 변형과 가대 방향의 시각 전달은 후속 작업이다.
- 기준 홈 맞추기는 현재 버튼으로 확인하는 단순화된 조작이다. 실제 홈을 확대해 돌려 맞추는 기구 조작은 추가 개선 항목이다.
