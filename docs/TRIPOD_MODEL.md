# 1단계 삼각대 교육 모형

2026-09-04. 특정 제품 사양이나 정밀 역학 모형이 아닌, 관찰 → 판단 → 조절을 위한 가상 수치다.

## 계산

- 북쪽을 화면 위로 둔다. 세 발의 평면 좌표(mm)는 N=(0,300), SW=(-150√3,-150), SE=(150√3,-150).
- 연장량 e는 0~60mm, 초기값은 각각 24mm. 공통 기본 높이를 생략한 유효 지지 높이 h=지면 높이+e×cos(20°).
- 관측지 A의 지면 높이(N,SW,SE)는 (0,-12,8)mm, B는 (10,6,-10)mm. 모두 단단한 지면이며 지반 침하·미끄러짐은 모델링하지 않는다.
- 동쪽 경사 p=(hSE-hSW)/(300√3), 북쪽 경사 q=(hN-(hSW+hSE)/2)/450.
- 상판 기울기=atan(√(p²+q²)). 기포는 높은 쪽으로 이동하도록 화면 좌표를 (900p,-900q)px로 표시한다. 수준기 테두리를 벗어나지 않도록 이동 거리는 64px에서 제한한다.
- 가상 통과 허용치는 0.25°. 해당 시점의 기포 중심 이동은 약 3.93px이며, 반지름 12px 기포가 반지름 16px 목표 원 안에 들어가는 시각 판정과 맞춘다.
- 상판 그림의 X/Y 회전은 경사를 5배 강조한다. 이는 깊이감 있는 카메라 재구성이 아니라 같은 모델을 보여주는 2D 이미지의 기울기 표현이다.
- 같은 길이로 만드는 것이 정답은 아니다. 모든 유효 지지 높이를 같게 만드는 서로 다른 연장 조합이 허용되며, 전체 높이를 일정량 올려도 기울기는 유지된다.

## 상태와 안전 판정

`placed`, 다리별 `spread/extension/locked`, `groundChecked`, `supported`, `observed`, `checked`를 분리한다. 수평만 맞아서는 완료되지 않는다. 세 다리 펼침, 발끝 지지, 재잠금, 상부 관찰과 최종 확인이 필요하다.

- 길이 잠금은 상판을 받친 뒤 한 다리씩만 푼다.
- 잠긴 다리는 움직이지 않는다. 조절 범위 밖 값과 비정상 수치는 차단한다.
- 어느 다리든 풀려 있으면 손 떼기와 최종 확인을 차단한다.
- 잠금/연장량을 바꾸면 기존 최종 확인을 무효화한다.
- 이미 가대나 경통이 올라간 경우 앞 단계로 돌아와도 다리 조절은 차단한다. 이는 이 시뮬레이션의 안전한 연습 범위 제한이지, 모든 실물 장비에서 어떠한 높이 조절도 불가능하다는 뜻은 아니다.
- 설치 원의 실제 화면 영역으로 드롭을 판정한다. Enter/Space 설치도 같은 상태 전이를 사용한다.

## 저장·평가 범위

현재 로컬 저장 키는 `telescope-lab-progress-mount-v3`이다. 직전 `telescope-lab-progress-tripod-v2`에서 유효한 삼각대만 이행하며 이전 키들은 보존한다. 올바른 삼각대 완료 상태가 없는 저장값은 후속 단계 성취로 복원하지 않는다.

이벤트는 동작, 대상 다리, 차단 여부, 설명, 순번을 최대 160건 보존하고 힌트 횟수를 별도 집계한다. 장시간 실습의 전체 이력 또는 전 과정 평가라고 표현하지 않는다. 브라우저 간 공유·교사 대시보드는 없다.

## 남은 시각적 한계

- 접힌 모습/모두 펼친 모습/상부 모습은 기존 캐릭터형 이미지를 재사용한다. 일부 다리만 펼친 중간 상태는 글자 상태로 표시하며 해당 중간 그림은 없다.
- 다리 연장량은 계산과 기포, 상판 회전 및 전체 보기의 이미지 변형에 반영된다. 원본 픽셀을 분할해 위쪽 다리·아래 연장부를 연결하고 발끝 기준점은 고정한다. 목부/칼라 등도 약간 변형되는 2D 근사이며 실제 강체의 모든 부품을 분리한 모형은 아니다.
- 고정 발 위치와 일정 다리 각도의 작은 기울기 근사다. 실제 강체 삼각대의 모든 힌지·발 이동·하중을 동시 해석하지 않는다.
- 북쪽 표시는 이 모형의 방향 기준이지 제조사별 공통 부품 위치 규격이나 극축 정렬 완료 표시가 아니다.

## 검증

`pnpm test:tripod`: 방향성, 공통 연장 불변성, 두 지면의 여러 해, 잠금/받침 차단, 재확인 무효화, 범위·이력 제한, 저장 데이터 검증 등 16개.

UI: 원 밖/안 드래그, 상부 전환, 키보드 다리 조절, 잠금 차단, 기포 중심+풀린 다리 완료 거부, 재잠금·최종 확인 후 2단계 연결, 중간 및 완료 저장 복원. PC와 390×844 모바일 화면에서 기포·조절부·피드백을 확인했다.

## 이미지 연동 추가

`lib/tripod-rig.ts`가 1024×1536 원본의 상판·커프·발끝 기준점을 관리한다. 유효 지지 높이를 원본 좌표의 2px/mm로 강조해 표현한다. 화면 px/mm나 실제 제품 치수가 아니며 화면 크기에 따라 축소된다.

상판 중심은 세 높이 평균을 따라 이동한다. 각 위쪽 다리와 연장부는 같은 커프 점을, 연장부와 신발은 같은 발목 경계를 공유한다. 각 발끝 중심은 지면 높이에만 의존한다. 공유 SVG 안에서 가대 결합면도 상판 기준점에 붙는다. `pnpm test:mount`가 두 지면과 극단값 조합의 연결 및 발끝 불변성을 검사한다.
