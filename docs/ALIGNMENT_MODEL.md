# 6단계 · 파인더 정렬과 목표 탐색

## 구현 범위 (2026-09-07)

관측 부속품 장착과 두 축 균형을 마친 뒤, 저배율 주망원경에 기준별 넣기 → 경통을 유지한 채 파인더 방향 조절 → 두 시야의 같은 별 확인 → 목성 탐색 → 주망원경에서 중심 확인으로 진행한다. 단순히 두 수치를 50에 맞추던 이전 6단계 판정은 사용하지 않는다.

- 가대 미동은 경통의 관측 방향을 바꾸므로 두 시야에 함께 작용한다. 파인더 조절은 두 광축 사이의 오프셋만 바꾼다. 십자선은 화면 중심에 고정된다.
- 기준별 중심 확인 전에 파인더를 조절하거나, 파인더 조절로 목성을 따라가거나, 다른 별을 중심에 넣고 확인하면 원인별 피드백을 준다.
- 정렬 중 경통 미동은 기준별 확인 증거를 취소한다. 이미 맞춘 파인더의 기하학적 오프셋 자체는 경통 이동으로 변하지 않는다.
- 목성 탐색 시작 버튼은 목표만 바꾸며 자동 조준하지 않는다. 파인더 시야에 보이는 것과 주망원경 중심에 있는 것을 별도로 판정한다. 마지막 확인 이후 미동하면 목표 확인을 취소한다.
- 앞 단계의 조립 상태 그림과 부속품·균형 위치를 유지한다. 이 그림은 결합 상태 표시이며 실제 경통 조준 각도를 애니메이션하지 않는다.
- 초점 관측을 시작한 뒤 6단계 재방문은 관찰 전용이다. 힌트와 원인별 조작 이력은 최대 160개까지 로컬에 보관한다. 교사용 평가 리포트는 아직 없다.

## 광학 및 운동 가정

실제 날짜의 천체 좌표가 아닌 작은 각도 영역의 평면 모형이다. 기준별 (0,0), 목성 (2.4,1.2), 식별용 동반별을 사용한다. 주망원경 시야 반경 0.5°, 파인더 2.5°, 중심 판정 0.071°는 교육용 가정으로 특정 제품 수치가 아니다. 별의 화면 크기와 목성 원반도 식별을 위한 과장이다.

천정미러가 있는 주망원경은 좌우 반전, 직시형 파인더는 상하·좌우 반전된 고정 배치로 비교한다. 실제 회전 방향은 장비의 광학 구성과 접안부 자세에 따라 달라진다. 적경·적위 미동 버튼은 국소 평면에서의 각도 변화이며 구면 좌표 변환, 적위에 따른 적경 이동량 변화, 미동 기어의 범위·백래시·시간에 따른 일주운동은 아직 모형화하지 않았다.

파인더의 ± 버튼은 방향 조절 나사 조합의 결과를 뜻한다. 실제 나사 개수·나사 회전량이나 고정나사의 조임을 재현한 것이 아니다. 슈 고정과 두 축 클러치는 잠긴 상태를 유지한다. 클러치를 풀어 크게 움직이는 조작은 별도 범위로 남겨 둔다.

기준별 식별이 가능한 저배율 초점에서 시작한다고 안내한다. 7단계의 세밀한 목성 초점 조절과 구분한다. 태양 탐색 시나리오는 제공하지 않으며 태양·태양 근처 관측 금지를 안내한다.

파인더 정렬과 극축 정렬은 별개이다. 2단계의 북쪽·위도 설정은 대략적인 준비일 뿐이다. 실제 극축 시야, 천구의 극 찾기, 정밀 방위·고도 조절은 미구현이며 이 단계 통과로 극축 정렬을 완료했다고 표시하지 않는다.

## 저장 이행

새 키 `telescope-lab-progress-alignment-v7`를 우선 사용한다. 기존 v6 이하 키는 보존하며 각 단계의 복원 검사를 통과한 1~5단계 상태만 이어받는다. 과거 6·7단계 완료는 새 실습 완료로 추정하지 않고 6단계에서 다시 확인한다. 새 저장은 정렬 중간 상태와 목표 탐색 진도를 복원하되 완료 플래그와 시야 기하를 함께 검증한다.

## 확인

- `scripts/alignment.test.mjs` 16개: 두 시야 연동/독립 조절, 선행 조건, 다른 별 확인, 경통 이동에 따른 확인 취소, 자동 조준 없음, 파인더만 보이는 목표, 최종 확인, 관찰 전용, 복원·비정상 데이터 및 이력 제한.
- 전체 89개 자동 테스트 통과. PC 1280×800 및 모바일 390×844에서 실제 UI 조작과 시각 확인. 구버전 완료 테스트 기록이 6단계로 이행되는 것, 중간 정렬 새로고침 복원, 목성 확인 후 7단계 연결을 확인했다.
- 모바일 조작 패널이 시야 아래에서 독립 스크롤되도록 수정했다. 시야와 조작 버튼의 겹침을 제거하고 가로 넘침이 없음을 확인했다.
- 운영 빌드·TypeScript·결합 CSS 검사 통과. 운영용 로컬 서버에서 완료 상태 복원과 최종 화면을 확인했으며 콘솔 오류·경고는 없었다. 초점 실습 이후 재방문의 조작 차단도 확인했다.
- 새 모듈 대상 lint 통과. 전체 lint는 기존 UI/레거시 페이지/빌드 검사 스크립트의 오류가 남아 실패하며, 이번 작업에서 관련 없는 코드는 수정하지 않았다. 테스트용 임시 진도 주입 페이지는 확인 후 제거하여 운영 빌드에 포함하지 않았다.
