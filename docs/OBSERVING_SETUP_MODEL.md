# 관측 부속품과 두 축 균형 — 교육용 모형

## 실행 흐름

기존 1~4단계를 유지한다. 실행 5단계 내부에서 파인더/천정미러/접안렌즈의 고정을 마친 뒤 적경·적위를 시험한다. 6단계는 파인더 정렬, 7단계는 접안 시야 열기부터 시작한다. 새 전체 교육과정의 단계 번호 통합은 이번 범위가 아니다.

부속품 상태는 준비물대, 입구, 안착, 고정, 고정 확인으로 구분한다. 몸체 받침·고정나사 여유·관찰을 별도로 기록한다. 천정미러에 접안렌즈가 달려 있으면 먼저 접안렌즈를 분리해야 한다. 장착한 구성을 바꾸면 두 축의 확인을 취소한다.

## 계산 가정

아래 값은 가상 수업용 장비 설정이며 특정 제품의 사양/실측이 아니다. g는 모든 항에 공통이므로 비교에서 생략한다.

| 부품 | 질량 kg | 경통 기준점에서 접안부 방향 거리 mm |
| --- | --- | --- |
| 경통 | 3.2 | 15 |
| 파인더 | 0.35 | -60 |
| 천정미러 | 0.20 | 220 |
| 접안렌즈 | 0.15 | 250 |

- 적경 회전 경향: `관측 구성 총질량 × 0.25 - 3 × (0.10 + 0.006 × 무게추 위치)` kg·m. 양수면 경통 쪽이 내려간다. 위치 입력 15~75는 교육용 좌표이며 실제 눈금이 아니다. 허용 범위 ±0.035 kg·m.
- 적위 회전 경향: `Σ(질량 × 거리) / 1000 - 총질량 × 경통 전진량 / 1000` kg·m. 양수면 접안부 쪽이 내려간다. 전진량 ±60 mm의 가상 안전 이동 범위를 사용하며 양수는 대물렌즈 방향 이동이다. 허용 범위 ±0.008 kg·m.
- 이상화한 축 분리 모형: 경통의 앞뒤 이동은 적위 모멘트에 영향을 주며, 적경축에서의 반경은 일정하다. 측면 비대칭·마찰·기어·케이블·접안부 회전·3D 관성은 계산하지 않는다.
- 여러 인접 위치에서 허용 범위를 만족한다. 중앙 50을 정답으로 사용하지 않는다. 최종 통과는 수치뿐 아니라 실제 시험 이벤트와 재잠금이 있어야 한다.

## 시각·조작

`ObservingTube`는 이전 경통 그림에 기존 부속품 PNG를 외곽 클립/변환해 연결한다. 부속품 원본 결합 기준점과 소켓 기준점은 코드에 명시된다. 드래그는 누른 위치가 아니라 이동한 부품 결합점을 판정한다. 전체/결합부/뒤쪽 단계에서 같은 부품 상태를 사용한다.

균형 화면은 실제 가대의 3차원 회전 애니메이션이 아니라 축을 펼쳐 보는 **2D 단면 모형**이다. 동일한 경통·부속품/무게추 이미지와 회전 중심/기준선을 표시한다. 시험 후 계산 모멘트의 부호와 크기에 따라 최대 13도로 회전 경향을 확대해 표시한다. 실물의 정확한 회전각이나 시험 시간 예측이 아니다.

장비 받침 → 한 축 클러치 해제 → 위치 고정이 잠긴 상태에서 회전 시험 → 해당 위치 고정 해제·이동 → 재고정·재시험 → 축 잠금 흐름이다. 손을 완전히 놓지 않는다. 두 축 동시 해제와 풀린 상태에서 보기 전환을 막는다. 정렬 이후에는 조작을 막고 완료 구성을 관찰할 수만 있다.

## 저장·검증·한계

- 저장 키 `telescope-lab-progress-observing-v6`. 직전 유효 1~4단계만 이전하며 모든 이전 키를 보존한다. 새 부속품/균형 성취는 이전 숫자 진도로부터 추정하지 않는다.
- `scripts/observing-setup.test.mjs`는 선행 조건, 안전, 구성 변경, 모멘트 방향, 완료 증거, 복원과 이벤트 한계를 검증한다. 이벤트 최대 160건이며 힌트는 안전 실패가 아니다.
- 전 과정 설치 리포트는 아직 없다. 6단계 정렬과 7단계 초점 판정은 기존 연습이다. 정밀 극축 정렬과 목표 천체 탐색은 후속 범위다.
- 손/접촉력/낙하/나사 토크를 계산하지 않는다. 실제 실습은 교사 감독과 해당 장비 설명서를 따른다.

원리 참고: [Celestron Advanced VX 설명서 pp.8~9](https://celestron-site-support-files.s3.amazonaws.com/support_files/Advanced_VX_Series_Telescopes_Manual_Eng_F.pdf). 특정 제품의 자동 추적용 편중 설정을 재현하지 않으며, 일반적인 정적 균형과 통제된 취급을 연습한다.
