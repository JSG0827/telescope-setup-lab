# 3단계 무게추 설치 — 구현 기준

일반형 소형 굴절망원경·수동 적도의 구성. 현재 실행 단계 번호는 기존 7단계를 유지하며, 교육과정 v2의 경통 소단계 통합은 아직 하지 않았다.

## 시작 조건과 절차

- 삼각대 수평·가대 고정과 기본 방향 확인이 유효해야 장착한다.
- 무게추 봉은 이미 장착되어 아래로 향하고, 두 축 클러치는 잠긴 상태를 가정한다. 학생이 봉 고정·축 잠금을 관찰한다. 봉 자체의 체결 및 축 자세 변경 실습은 이번 범위에 없다.
- 봉 끝 안전장치를 풀어 보관한다. 준비물대에서 무게추 고정나사를 조금 풀어 구멍을 비운다. 두 동작 사이의 순서는 강제하지 않는다.
- 무게추 가운데 기준점으로 봉 끝을 겨냥해 드래그한다. 봉 옆면에 놓아서는 끼울 수 없다. Enter/Space는 같은 상태 판정을 사용한다.
- 장착하면 받친 상태가 된다. 받침·고정나사·봉 끝 안전장치·미끄러짐 확인·최종 확인을 서로 다른 상태로 관리한다.
- 무게추 위치가 고정되지 않았거나 안전장치가 없거나 미끄러짐을 확인하지 않았으면 손 떼기를 차단한다. 안전장치는 고정나사를 대신하지 않는다.
- 무게추를 받치고 고정나사를 푼 상태에서만 봉 위 위치를 바꿀 수 있다. 위치 변경이나 잠금 변경은 기존 확인을 무효화한다.
- 경통 장착 뒤 재방문하면 관찰·힌트·완료 확인만 허용한다. 축 균형은 이후 단계에서 다룬다.

## 시각 좌표와 교육 모형

`counterweightRig`는 `tripodRig`의 실제 상판 결합점에서 가대 PNG의 배치 좌표를 계산한다. 무게추 중심, 봉 끝 안전장치, 삽입 판정 원이 동일한 좌표를 사용한다. 확대/전체 시점에도 같은 그림을 쓴다.

기존 `telescope-stage-03-v4.png`에서 무게추·안전장치 부분만 SVG 클리핑으로 재사용한다. PNG를 수정하거나 새 도형으로 무게추를 만들지 않는다. 조작점의 원과 라벨은 교육용 표시이며 실물 부품이 아니다. 전체 시점의 삽입 판정 원은 마우스 정밀도가 성취를 좌우하지 않도록 넓게 표시한다.

봉을 따라 가대 쪽 15%~끝 쪽 75% 사이에서 임시 위치를 조절한다. 이 값은 실측 거리·토크·균형 정답이 아니라 삽입 깊이와 끝의 여유를 보장하는 2D 실습 범위다. 여러 위치에서 완료할 수 있으며 중앙값을 요구하지 않는다. 질량·모멘트 계산과 물리적인 낙하·클러치 회전 모형은 아직 없다. 미끄러짐 시험은 실제 낙하 없이 받친 손에서 관찰되는 현상을 문장으로 알려준다.

이후 4~7단계와, 1·2단계 재방문 화면의 모든 장착물을 공유 그림으로 통합하는 작업은 남아 있다. 해당 이전 화면은 장착물 변경을 상태상 차단하지만 모든 부품을 그림으로 표시하지는 않는다.

## 저장과 완료 증거

- 저장 키: `telescope-lab-progress-counterweight-v4`.
- 기존 `mount-v3` / `tripod-v2` / 최초 기록은 삭제하거나 덮어쓰지 않는다. 유효한 삼각대·가대 상태만 이어받고 이전 무게추 완료로 새 안전 확인을 통과시키지 않는다.
- 무게추 중간 상태와 받침·잠금·위치·확인 상태를 복원한다. 모순된 저장값은 새 실습으로 되돌린다.
- 최근 160건의 행동·차단 여부·피드백·요청 이동량을 기록한다. 아직 설치 리포트 화면이나 서버 수집 기능은 아니다.
