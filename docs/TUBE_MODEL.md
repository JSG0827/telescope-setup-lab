# 경통 설치 모형 — 구현 범위와 가정

일반형 소형 굴절망원경·수동 독일식 적도의를 위한 교육 모형이다. 특정 제조사 제품의 조작 횟수나 하중을 재현하지 않는다.

## 학습 목표와 상태

- 레일과 안장 홈을 관찰하고 긴 방향을 나란히 맞춘다.
- 본체·밴드 부근을 받친 상태에서 경통을 준비물대에서 안장으로 옮긴다.
- 홈 입구에 가져온 상태와 홈 안으로 완전히 안착한 상태를 구분한다.
- 안장 고정 손잡이로 고정하고, 받친 채 유격을 확인한 다음 손을 뗀다.
- 고정과 균형이 다르며, 최종 축 균형은 관측 부속품을 포함한 구성에서 확인한다.

`lib/tube.ts`가 판단을 담당한다. `inspected / aligned / supported / placed / seated / saddleOpen / clamp / tested / checked`를 별도로 보존한다. 1~3단계 안전 확인이 선행되어야 한다. 후속 축 또는 부속품 실습을 시작하면 되돌아온 4단계에서 재분해를 막는다.

실수는 실행 전 차단하고 이유와 다음 관찰 대상을 안내한다. 안전한 순서 변경(관찰 후 받침/방향/안장 여유 만들기의 순서)은 허용한다. 고정을 풀면 시험과 확인을 무효화한다. 사건은 최근 160건, 힌트 횟수는 별도 기록하며 아직 최종 리포트는 아니다.

## 시각 좌표

`lib/tube-rig.ts`의 레일 기준점 `(780,766)`과 가대 안장 `(607,123)`을 같은 삼각대 상판 좌표계로 변환한다. `TubeArt`는 기존 PNG 외곽 클립을 사용한다. 드래그 판정은 클릭한 지점이 아니라 이동한 레일 기준점을 기준으로 한다. 전체/확대와 3단계 재방문에 동일 이미지와 좌표를 쓴다.

부분 안착의 간격은 이해를 위한 확대 표현이다. 그림 위 조임 표시와 버튼은 동일 상태를 조작한다. 마우스와 Enter/Space는 동일한 설치 조건으로 판단한다.

## 명시적 한계

- 한 개의 대표 안장 손잡이와 3회의 ¼회전은 교육용 표현이며 실제 나사 수·토크·필수 회전 횟수가 아니다. 실물은 설명서에 따라 밀착할 만큼만 조인다.
- 경통을 올릴 때 두 축이 잠긴 초기 설치 자세를 가정한다. 이번 단계에서 축을 자유 회전시키는 물리 모형은 없다.
- 받침은 버튼으로 유지 의사를 표현한다. 손/접촉력/낙하/유격의 연속 물리 애니메이션은 없다. 유격 판정은 안착·잠금 상태 기반 설명이다.
- 기존 래스터 그림의 시점과 크기를 맞춘 2D 합성으로, 안장 턱의 실제 변형·조임 이동이나 3D 접촉 해석은 아니다.
- 후속 업데이트에서 5단계 부속품 선장착과 질량·거리 기반 균형을 구현했고, 3~7단계에 공유 조립 그림을 연결했다. 상세 범위는 `OBSERVING_SETUP_MODEL.md`를 따른다. 정렬/초점 판정의 개선과 전체 과정 리포트는 후속 작업이다.

## 저장·검증

저장 키 `telescope-lab-progress-tube-v5`는 이전 키를 삭제하지 않는다. 이전 저장의 유효한 1~3단계만 이어받고 경통 완료는 새로 확인한다. 불가능한 조합이나 다른 버전의 경통 기록은 초기 상태로 복구한다.

`pnpm test:tube`: 선행 조건, 부분 안착, 받침, 조임 한계, 확인 무효화, 안전한 재분리, 렌즈/클러치 실수, 후속 작업 잠금, 복원, 이벤트 한계, 공유 좌표를 검증한다. 브라우저 검증 기록은 `DEVELOPMENT_DIRECTION.md`에 보존한다.

원리 참고: [Celestron Advanced VX 사용 설명서, p.8 Attaching a Telescope](https://celestron-site-support-files.s3.amazonaws.com/support_files/Advanced_VX_Series_Telescopes_Manual_Eng_F.pdf). 축 잠금·무게추 고정 후 도브테일 장착과 고정 확인을 참고했으며, 이 프로그램이 해당 제품이라는 의미는 아니다.
