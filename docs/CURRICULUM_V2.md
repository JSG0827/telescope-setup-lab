# 교육과정 v2 — 기준 장비와 7단계 설계

상태: 특정 실물 모델 미확정. 현재 실행 번호 1~4는 삼각대·가대·무게추·경통을 유지하고, 5단계 안에서 관측 부속품을 먼저 장착한 뒤 두 축 균형을 맞춘다. 6은 파인더 정렬, 7은 초점이다. 아래 새 7단계 통합 설계와 실행 번호는 아직 동일하지 않다.

사용자 동의: 특정 제조사 모델 대신 현재의 일반형 소형 굴절망원경·수동 적도의 구성으로 개발한다.

## 1. 잠정 기준 장비

- 소형 굴절망원경 + 무게추가 있는 수동 독일식 적도의.
- 광학 파인더, 천정미러, 저배율 접안렌즈를 사용하는 현재 이미지 구성을 유지.
- 자동 도입(GoTo), 촬영용 정밀 극축 정렬, 태양 관측은 이번 범위 밖.
- 북반구 야간 육안 관측을 학습 상황으로 삼는다. 관측지 위도는 실제 학교 위치 확인 후 설정한다.
- 구경, 초점거리, 질량, 나사 개수, 하중 한계, 북쪽 다리 위치는 실측/설명서 확인 전 실물 사양처럼 표기하지 않는다.
- 계산용 가상 수치가 필요하면 교육용 가정임을 명시하고 장비 설정에서 관리한다.

## 2. 부품과 행동의 구분

| 부품/장치 | 역할 | 학생이 구분해야 하는 행동 |
| --- | --- | --- |
| 삼각대·다리 잠금 | 장비 지지 | 다리 펼치기, 길이 조절, 잠금은 별개 |
| 원형 수준기 | 상판 기울기 확인 | 기포를 보고 다리 높이를 선택; 극축 정렬과 다름 |
| 가대 결합 고정 | 가대를 삼각대에 고정 | 안착과 고정을 구분 |
| 방위·고도 조절부 | 극축의 방향 설정 | 경통의 적경·적위 회전과 구분 |
| 적경·적위 클러치 | 해당 축의 회전 제어 | 한 축씩 통제하며 풀기·시험·잠그기 |
| 무게추 고정나사·봉 끝 안전장치 | 위치 고정·이탈 방지 | 클러치를 푸는 것과 무게추 위치 잠금을 푸는 것은 별개 |
| 도브테일·경통 고정 | 경통 지지 | 축 균형을 위한 이동과 경통 분리를 구분 |
| 파인더·조절나사 | 주망원경과 같은 대상 가리키기 | 파인더 정렬은 극축 정렬이 아님 |
| 천정미러·접안렌즈·포커서 | 관측 구성·확대·초점 | 천체 찾기와 선명도 조절은 별개 |

렌즈 표면은 잡는 곳으로 만들지 않는다. 이 야간 실습에서는 태양 관측 기능을 제공하지 않는다. 실물 실습은 교사의 감독 및 해당 장비 설명서에 따른다.

## 3. 새 7단계의 학습 계약

단계 순서는 기본 학습 안내다. 최종 행동 허용은 단계 번호가 아니라 장비 상태로 판단한다.

| 단계 | 학생의 판단과 조작 | 완료 증거 | 선행 조건/실패 대응 |
| --- | --- | --- | --- |
| 01 관측 준비·삼각대 | 안정된 지면 판단, 다리 펼치기·잠금, 기포 관찰 후 다리 조절 | 지지 상태와 잠금이 유효하고 상판 기울기가 허용 범위 | 안전한 잘못된 높이 조절은 허용하고 기포 변화 표시 |
| 02 가대·기본 방향 | 결합 방향 확인, 안착·고정, 북쪽·위도에 맞춘 대략적 설정 | 가대가 고정되고 기본 방향 설정을 확인 | 불안정한 삼각대에는 장착 차단; 이유 안내 |
| 03 무게추·경통 | 무게추 설치·안전장치, 경통 받치기·안착·잠금 확인 | 무게추·경통 고정과 이탈 방지 확인 | 받치지 않고 장착 잠금을 푸는 행동은 차단 |
| 04 관측 부속품 | 파인더·천정미러·접안렌즈 장착, 고정 확인 | 관측할 구성 전체가 고정됨 | 장착 부속품의 질량·위치를 이후 균형 계산에 전달 |
| 05 두 축 균형 | 축별 시험 자세, 한 축씩 통제, 무게추/경통 이동, 재시험·잠금 | 두 축의 회전 경향이 허용 범위이고 시험·재잠금을 완료 | 고정나사·클러치 구분; 부속품 변경 시 균형 확인 무효화 |
| 06 정렬·목표 탐색 | 기준 대상의 파인더 정렬, 극축 정렬 확인·보정, 목표를 주경 시야로 도입 | 파인더/주경 시선 일치, 극축 방향 확인, 목표가 주경 시야 안 | 망원경을 단순히 북쪽으로 돌리는 것으로 극축 통과 처리 금지 |
| 07 초점·관측·리포트 | 상의 변화를 보며 초점 조절, 관측 특징 기록, 수행 되돌아보기 | 초점 상태와 목표 관측 확인, 실제 행동 기록 기반 리포트 | 고정 정답 50 제거; 속도·드래그 정밀도만으로 평가 금지 |

극축 정렬의 허용 오차와 각 단계의 수치 기준은 물리 모형 구현 때 명시한다. 설명서마다 가능한 작업 순서가 다르므로 위 표를 모든 망원경의 유일한 설치 순서라고 표현하지 않는다.

## 4. 현재 기능의 이동 계획

| 현재 기능 | 새 위치 | 추가로 필요한 작업 |
| --- | --- | --- |
| 1 삼각대 | 01 | 다리별 상태·연장부 이미지·상판·기포·잠금 구현. 지면 선택 판단과 펼침 중간 그림은 추가 필요 |
| 2 가대 | 02 | 기준 홈·안착·하부 고정·유격·기본 방위/위도 설정 구현. 특정 실물 재현·정밀 극축 정렬 아님 |
| 3 무게추 + 4 경통 | 03의 소단계 | 두 실습의 안전 상태 구현 완료. 번호 통합은 미실시 |
| 6의 파인더 설치 + 7의 접안부 설치 | 04 | 실행 5단계의 선행 소단계로 이동 완료. 뒤쪽 정렬/초점에서 재장착하지 않음 |
| 5 축 균형 | 05 | 관측 부속품 포함 질량·거리 계산, 부품 이동·회전 경향·안전 상태 구현. 2D 교육 모형 |
| 6의 파인더 정렬 | 06 | 극축 정렬·목표 탐색 신규 구현 |
| 7의 초점 + 완료 화면 | 07 | 번짐·진동·대기 비교와 수동 관찰 확인 구현. 전 과정 리포트는 미구현 |

## 5. 이행 시 지켜야 할 것

- `lib/curriculum.ts`의 plannedCurriculum은 설계용이다. 아직 실제로 할 수 없는 기능을 현재 메뉴에 노출하거나 완료 처리하지 않는다.
- 현재 `telescope-lab-progress` 데이터는 보존한다. v2는 별도 버전 키와 식별자 기반 상태를 사용하고, 이전 결과를 새 과정의 성취로 인정하지 않는다.
- 단계 번호와 장착 이미지 번호를 분리한다. 특히 부속품 장착 후 균형 화면에서도 부속품이 사라지지 않아야 한다.
- 잠금/안착/받침 상태, 실제 조절량, 판정 결과, 힌트 이벤트를 별도로 관리한다. 현재의 values 배열과 고정 50 판정을 점진적으로 교체한다.
- 최종 리포트에는 관측하지 않은 항목을 미평가로 표시한다. 힌트 사용 자체를 안전 실패로 처리하지 않는다.

## 6. 구현한 단위: 01의 상태·안전 기반

아래 범위는 `lib/tripod.ts`와 `components/tripod-lesson.tsx`에서 실행된다. [계산 가정과 한계](TRIPOD_MODEL.md)를 함께 확인한다. 모든 새 7단계가 구현된 것은 아니다.

1. 삼각대 상태를 다리별 펼침·길이·잠금과 지면 조건으로 정의.
2. 안정성·수평·잠금의 판정 함수를 UI 밖에서 테스트.
3. 높이와 상판 기울기/기포를 연결. 초기 조건이 달라도 같은 원리로 풀리게 할 것.
4. 잠긴 다리 조절 시 원인 설명, 불안정한 상태의 가대 장착은 차단.
5. 키보드와 드래그의 결과를 동일하게 검사. 작동 방향, 시점 전환, 화면 크기별 좌표도 시각 검증.
6. 최소 이벤트: 관찰, 다리 선택, 길이 변경, 잠금 변경, 힌트 요청, 안전 차단, 수평 재확인.

## 참고 자료와 미확정 사항

4단계는 [경통 모형](TUBE_MODEL.md), 5단계는 [부속품·균형 모형](OBSERVING_SETUP_MODEL.md)을 따른다. 부속품 장착 뒤 최종 균형으로 이어지는 실행 흐름을 구현했다. 6단계는 [정렬·탐색 모형](ALIGNMENT_MODEL.md)으로 기준별 정렬과 목성 탐색을 구현했다. 7단계는 [초점 모형](FOCUS_MODEL.md)으로 초점 오차·번짐·진동·대기 비교·수동 관측 확인을 구현했다. 정밀 극축 정렬과 전 과정 리포트는 아직 구현하지 않았다.

원리 확인용이며 현재 이미지가 해당 제조사의 특정 모델이라는 의미는 아니다.

- [Celestron: 적도의 축 균형](https://www.celestron.com/blogs/knowledgebase/how-do-i-balance-my-telescope-on-an-equatorial-mount)
- [Celestron: 수동 적도의 극축 정렬](https://www.celestron.com/blogs/knowledgebase/how-do-you-align-and-polar-align-using-a-manual-eq-mount)
- 사용자 확인 필요: 실제 망원경/가대 모델명 또는 사진, 관측지, 실습 시간. 모델 정보가 없어도 일반형 설계·독립적인 소프트웨어 작업은 계속한다.
